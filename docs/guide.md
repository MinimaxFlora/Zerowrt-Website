## 在 LuCI 中升级

1. 打开路由器管理页面，进入 **系统 → 在线升级**。
2. 点击 **检查更新**，确认新版本号、构建时间和更新日志。
3. 点击 **下载**，等待 SHA256 校验完成。
4. 点击 **安装**，设备会自动重启。默认保留当前配置。

> 升级过程中不要断电。升级完成后管理地址、WiFi 名称和密码保持不变。

## 手动下载

在首页选择对应设备，下载 `*-squashfs-sysupgrade.bin`，然后在 LuCI 的
**系统 → 备份/升级** 中上传固件。跨大版本或首次安装时建议不保留配置。

## 校验镜像

每个版本页面都会显示 SHA256。下载完成后可以本地校验：

```bash
sha256sum zerowrt-*.bin
```

只有哈希与页面一致时才建议刷入。

## 常见问题

### 检查更新提示没有适用固件

页面「当前固件」里的设备标识就是插件检查的 key。确认下载的是对应设备的固件，
或在 OTA 配置里手动指定设备标识。

### 下载失败

固件默认下载到 `/tmp`，空间不足时请先清理设备内存，或使用手动下载。
