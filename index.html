在线升级（OTA）

ZeroWrt 自带 luci-app-ota：在 LuCI 里检查、下载、校验并安装固件，无需手动上传文件。

1

打开升级页面

LuCI → 系统 → OTA Firmware Update（在线升级）。

2

检查并下载

页面会自动比对构建时间；下载完成后强制校验 SHA256，并用 sysupgrade -T 预检镜像。

3

安装

默认保留配置升级；设备重启后即为新固件。也可以命令行执行 ota check / ota download / ota apply --keep 1。

更新索引地址 https://ota.tatalvpai.vip/ota.json

GitHub 下载慢时，可在「配置」里选择加速站，默认 gh-proxy.tatalvpai.vip。
